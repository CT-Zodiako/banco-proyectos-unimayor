50 PROYECTOS PRÁCTICOS DE IoT  
Ingeniería Informática - Noveno Semestre 
  
Información General 
Esta colección contiene 20 proyectos prácticos diseñados específicamente para 
estudiantes de noveno semestre de Ingeniería Informática, con énfasis en tecnologías 
IoT (Internet de las Cosas). Los proyectos están distribuidos en cinco áreas 
tecnológicas principales: 
• SBC-IoT (Single Board Computer - Internet of Things): 4 proyectos 
• AIoT (Inteligencia Artificial + IoT): 4 proyectos 
• IoT Hacking y Ciberseguridad: 4 proyectos 
• IoT con Big Data y Analítica: 4 proyectos 
• IoT con Visión Artificial: 4 proyectos 
Características de los Proyectos 
• Duración: Un semestre académico completo 
• Nivel: Intermedio-Avanzado 
• Presupuesto: Bajo costo 
• Software: Exclusivamente libre y de código abierto 
• Hardware: ESP32, Raspberry Pi, Arduino, sensores económicos 
  
PROYECTOS DE SBC-IoT 
Proyecto 1: Sistema de Monitoreo Agrícola Distribuido con MQTT 
Sector Agricultura de precisión y agricultura 
inteligente 
Área Tecnológica SBC-IoT 
Complejidad Intermedio 
 
Los agricultores carecen de información en tiempo real sobre condiciones del suelo y 
clima, lo que genera desperdicio de agua, bajo rendimiento de cultivos y pérdidas 
económicas por decisiones basadas en intuición en lugar de datos precisos. 
Objetivo General 
Desarrollar un sistema de monitoreo agrícola distribuido basado en SBC-IoT que 
permita la recolección, análisis y visualización de datos ambientales en tiempo real para 
optimizar el uso de recursos y mejorar la productividad agrícola. 
Objetivos Específicos 
1. Implementar una red de sensores ESP32 que monitoreen humedad del suelo, 
temperatura y luminosidad en múltiples puntos del cultivo. 
2. Configurar un gateway MQTT en Raspberry Pi que centralice datos y permita 
visualización en dashboards web mediante Grafana. 
3. Desarrollar algoritmos de análisis de series temporales que generen alertas 
predictivas sobre necesidades de riego y condiciones adversas. 
 
Descripción 
Red de sensores distribuidos en cultivo que monitorean humedad del suelo, 
temperatura y luz, centralizando datos en Raspberry Pi que actúa como gateway MQTT 
para visualización en dashboard web. 
Hardware Necesario 
• Raspberry Pi 3 B+ (1 unidad - nodo central) 
• ESP32 (3-4 unidades - nodos sensores) 
• Sensores DHT22 (temperatura/humedad ambiente) 
• Sensores de humedad de suelo capacitivos (4 unidades) 
• Sensores LDR (luminosidad) 
• Fuentes de alimentación 
• Cableado y protoboards 
Software y Tecnologías 
• Sistema operativo: Raspberry Pi OS 
• Broker MQTT: Mosquitto 
• Node-RED para flujos de datos 
• InfluxDB (base de datos de series temporales) 
• Grafana para dashboards 
• Python para scripts en Raspberry Pi 
• Arduino IDE/PlatformIO para ESP32 
Habilidades Desarrolladas 
• Arquitecturas IoT distribuidas 
• Protocolos de comunicación (MQTT) 
• Integración SBC-microcontroladores 
• Visualización de datos en tiempo real 
• Gestión de bases de datos de series temporales 
  
Proyecto 2: Gateway IoT Multi-Protocolo para Edificio Inteligente 
Sector Domótica e Inmótica (edificios 
inteligentes) 
Área Tecnológica SBC-IoT 
Complejidad Avanzado 
 
Los edificios inteligentes utilizan dispositivos de diferentes fabricantes con protocolos 
incompatibles, generando silos de información, dificultad de gestión centralizada y 
costos elevados de integración. 
Objetivo General 
Diseñar e implementar un gateway IoT multi-protocolo basado en Raspberry Pi que 
unifique la gestión de sistemas de iluminación, climatización y control de accesos en 
edificios inteligentes. 
Objetivos Específicos 
4. Integrar comunicación MQTT, HTTP y Modbus en un único gateway para 
interoperabilidad entre dispositivos heterogéneos. 
5. Desarrollar una interfaz web responsiva que permita monitoreo y control centralizado 
de todos los subsistemas del edificio. 
6. Implementar reglas de automatización basadas en eventos que optimicen el 
consumo energético según ocupación y horarios. 
 
Descripción 
Raspberry Pi actuando como gateway que integra múltiples protocolos (MQTT, HTTP, 
ModBus) para controlar iluminación, climatización y accesos en un edificio, con interfaz 
web de administración. 
Hardware Necesario 
• Raspberry Pi 4 (1 unidad) 
• ESP32 (3 unidades para diferentes zonas) 
• Relés de 4 canales (2 unidades) 
• Sensores PIR (movimiento - 4 unidades) 
• DHT22 (3 unidades) 
• LEDs y módulos de iluminación 
• Sensor magnético de puertas (2 unidades) 
Software y Tecnologías 
• Node-RED como orquestador principal 
• Mosquitto MQTT broker 
• Node.js para servidor web 
• SQLite para almacenamiento local 
• React.js para interfaz web (opcional: HTML/CSS/JS vanilla) 
• Python para automatizaciones 
Habilidades Desarrolladas 
• Integración de múltiples protocolos IoT 
• Desarrollo de interfaces web responsivas 
• Arquitectura de microservicios 
• Automatización basada en reglas 
• Gestión de dispositivos heterogéneos 
  
Proyecto 3: Sistema de Monitoreo Meteorológico Local con Predicción 
Sector Meteorología y monitoreo ambiental 
Área Tecnológica SBC-IoT 
Complejidad Intermedio 
 
Las predicciones meteorológicas generales no consideran microclimas locales, lo que 
genera inexactitudes críticas para agricultura, eventos al aire libre y planificación de 
actividades sensibles al clima. 
Objetivo General 
Construir una estación meteorológica inteligente que capture datos climáticos locales y 
los correlacione con APIs meteorológicas públicas para generar predicciones híbridas 
más precisas. 
Objetivos Específicos 
7. Implementar un sistema de sensores meteorológicos (temperatura, humedad, 
presión, viento, lluvia) con registro continuo de datos. 
8. Integrar datos locales con APIs de OpenWeatherMap para análisis comparativo y 
calibración de modelos. 
9. Desarrollar algoritmos de machine learning que mejoren la precisión de predicciones 
considerando patrones históricos locales. 
 
Descripción 
Estación meteorológica completa que captura datos locales (temperatura, humedad, 
presión, viento) y los compara con APIs meteorológicas públicas para generar 
predicciones locales mejoradas. 
Hardware Necesario 
• Raspberry Pi 3 B+ 
• ESP32 (para sensores exteriores) 
• DHT22 
• Sensor BMP280 (presión atmosférica) 
• Anemómetro (puede construirse con sensor Hall y imanes) 
• Pluviómetro DIY 
• GPS NEO-6M (geolocalización) 
Software y Tecnologías 
• Python para captura y procesamiento 
• ThingSpeak para almacenamiento en la nube 
• APIs públicas: OpenWeatherMap 
• Pandas para análisis de datos 
• Matplotlib para gráficos 
• Cron para tareas programadas 
Habilidades Desarrolladas 
• Integración con APIs REST 
• Procesamiento de datos meteorológicos 
• Análisis comparativo de datos 
• Calibración de sensores 
• Visualización científica de datos 
  
Proyecto 4: Control de Invernadero Automatizado con Retroalimentación 
Sector Agricultura de precisión y agricultura 
inteligente 
Área Tecnológica SBC-IoT 
Complejidad Avanzado 
 
El control manual de invernaderos genera desperdicio de recursos, condiciones 
subóptimas para cultivos y requiere supervisión constante, limitando la escalabilidad y 
rentabilidad de la producción agrícola protegida. 
Objetivo General 
Desarrollar un sistema de automatización integral para invernaderos que controle 
dinámicamente riego, ventilación e iluminación mediante retroalimentación de sensores 
ambientales y control remoto. 
Objetivos Específicos 
10. Implementar sensores de temperatura, humedad y humedad de suelo con 
actuadores controlados vía Raspberry Pi y Arduino. 
11. Desarrollar algoritmos de control PID que mantengan parámetros ambientales en 
rangos óptimos de forma autónoma. 
12. Crear una aplicación móvil con Blynk que permita monitoreo remoto y ajuste manual 
de parámetros de cultivo. 
 
Descripción 
Sistema de control climático para invernadero que ajusta automáticamente riego, 
ventilación e iluminación según parámetros ambientales, con control remoto vía 
aplicación web. 
Hardware Necesario 
• Raspberry Pi 4 
• Arduino Nano (2 unidades para control de actuadores) 
• DHT22 (2 unidades) 
• Sensores de humedad de suelo (4 unidades) 
• Relés (6 canales) 
• Electroválvulas para riego (2 unidades) 
• Ventiladores DC 12V (2 unidades) 
• Tiras LED para iluminación suplementaria 
• LDR (sensor de luz) 
Software y Tecnologías 
• Python con GPIO para Raspberry Pi 
• Blynk (versión gratuita) para interfaz móvil 
• MQTT para comunicación 
• Node-RED para lógica de control 
• InfluxDB y Grafana para históricos 
Habilidades Desarrolladas 
• Sistemas de control realimentados 
• Automatización agrícola 
• Lógica de control PID básica 
• Interfaces móviles IoT 
• Gestión energética 
  
PROYECTOS DE AIoT (INTELIGENCIA ARTIFICIAL + IoT) 
Proyecto 5: Clasificación Inteligente de Residuos con Visión Artificial 
Sector Gestión medioambiental y 
sostenibilidad 
Área Tecnológica AIoT + IoT con Visión Artificial 
Complejidad Avanzado 
 
La clasificación manual de residuos es ineficiente, costosa y propensa a errores 
humanos, generando contaminación cruzada que reduce las tasas de reciclaje efectivo 
y aumenta la contaminación ambiental. 
Objetivo General 
Diseñar un sistema de clasificación automática de residuos basado en visión artificial y 
deep learning que identifique y separe materiales (plástico, vidrio, papel, orgánico) en 
tiempo real. 
Objetivos Específicos 
13. Entrenar y optimizar un modelo MobileNet mediante transfer learning para 
clasificación de residuos con precisión >85%. 
14. Implementar un sistema mecatrónico con servomotores que dirija residuos a 
contenedores específicos según clasificación. 
15. Desarrollar interfaz de monitoreo que registre estadísticas de volumen y tipos de 
residuos procesados diariamente. 
 
Descripción 
Sistema de clasificación automática de residuos (plástico, vidrio, papel, orgánico) 
usando cámara y red neuronal en Raspberry Pi, con mecanismo de separación 
automatizado. 
Hardware Necesario 
• Raspberry Pi 4 (4GB RAM mínimo) 
• Cámara Raspberry Pi v2 o USB 
• Servomotores (3 unidades para compuertas) 
• Sensores ultrasónicos HC-SR04 (detección de objeto) 
• Arduino Nano (control de servos) 
• Iluminación LED para fotografía 
• Estructura mecánica simple (cartón/madera) 
Software y Tecnologías 
• TensorFlow Lite para inferencia 
• OpenCV para procesamiento de imágenes 
• Python con picamera 
• Modelo pre-entrenado MobileNet (transfer learning) 
• MQTT para comunicación con Arduino 
Habilidades Desarrolladas 
• Implementación de redes neuronales en edge 
• Transfer learning 
• Visión por computadora aplicada 
• Integración AI-hardware 
• Optimización de modelos para dispositivos limitados

Sector Automatización industrial (Industria 
4.0) 
Área Tecnológica AIoT 
Complejidad Avanzado 
 
Los defectos de fabricación detectados tardíamente generan costos por reproceso, 
pérdida de materiales y afectación de calidad, mientras que inspecciones manuales son 
lentas y subjetivas. 
Objetivo General 
Desarrollar un sistema de detección automática de anomalías en líneas de producción 
industrial mediante análisis multimodal de sensores y algoritmos de machine learning no 
supervisado. 
Objetivos Específicos 
16. Implementar sensores de vibración, sonido y temperatura en puntos críticos de la 
línea de ensamblaje con ESP32. 
17. Entrenar modelos de detección de anomalías (Isolation Forest, One-Class SVM) con 
datos de operación normal y defectuosa. 
18. Desarrollar sistema de alertas en tiempo real que notifique operarios y detenga 
producción ante anomalías críticas. 
 
Descripción 
Sistema de detección de productos defectuosos en línea de ensamblaje usando 
sensores (vibración, sonido, temperatura) y algoritmos de machine learning para 
identificar patrones anómalos. 
Hardware Necesario 
• Raspberry Pi 4 
• ESP32 con sensor MPU6050 (acelerómetro/giroscopio) 
• Módulo de micrófono MAX4466 
• Sensor de temperatura DS18B20 
• Arduino UNO para control de banda transportadora simulada 
• Motor DC con encoder 
• Buzzer y LEDs indicadores 
Software y Tecnologías 
• Python con scikit-learn 
• Algoritmos: Isolation Forest, One-Class SVM 
• Pandas y NumPy para procesamiento 
• MQTT para comunicación 
• Jupyter Notebook para entrenamiento 
• Node-RED para alertas 
Habilidades Desarrolladas 
• Machine learning no supervisado 
• Detección de anomalías 
• Procesamiento de señales 
• Mantenimiento predictivo 
• Integración de múltiples sensores

• SQLite para conteos locales

Habilidades Desarrolladas

• Procesamiento edge computing

• Sensor de temperatura MLX90614 (sin contacto) 
• Acelerómetro MPU6050 (detección de caídas)

Habilidades Desarrolladas

• Sistemas de alertas tempranas 
• Manejo de datos sensibles 
• Diseño de sistemas críticos 
  
PROYECTOS DE IoT HACKING Y CIBERSEGURIDAD 
Proyecto 9: Laboratorio de Análisis de Vulnerabilidades en Redes IoT 
Sector Control inteligente y sistemas 
embebidos 
Área Tecnológica IoT Hacking y Ciberseguridad 
Complejidad Avanzado 
 
Los dispositivos IoT presentan vulnerabilidades críticas de seguridad (credenciales 
débiles, puertos abiertos, tráfico sin cifrar) que son explotadas por atacantes, pero los 
desarrolladores carecen de entornos seguros para aprenderlas. 
Objetivo General 
Crear un laboratorio de ciberseguridad IoT que permita identificar, analizar y 
documentar vulnerabilidades comunes en dispositivos conectados mediante técnicas de 
ethical hacking. 
Objetivos Específicos 
25. Configurar entorno controlado con dispositivos IoT vulnerables intencionalmente 
para análisis de seguridad. 
26. Utilizar herramientas de pentesting (Nmap, Wireshark, Aircrack-ng) para identificar 
vectores de ataque comunes. 
27. Documentar vulnerabilidades encontradas y desarrollar guías de hardening para 
asegurar dispositivos IoT. 
 
Descripción 
Entorno controlado para identificar vulnerabilidades comunes en dispositivos IoT 
(credenciales débiles, puertos abiertos, tráfico sin cifrar) usando Raspberry Pi como 
plataforma de pentesting. 
Hardware Necesario 
• Raspberry Pi 4 (atacante) 
• Raspberry Pi 3 B+ (víctima - servidor IoT vulnerable) 
• ESP32 (2-3 unidades - dispositivos IoT vulnerables) 
• NodeMCU (dispositivo con configuración insegura) 
• Switch de red o router 
• Cables Ethernet 
Software y Tecnologías 
• Kali Linux ARM para Raspberry Pi 
• Wireshark para análisis de tráfico 
• Nmap para escaneo de puertos 
• MQTT broker sin autenticación (intencional) 
• Servidor web vulnerable (HTTP sin HTTPS) 
• Aircrack-ng para análisis WiFi 
• Python para scripts de explotación 
Habilidades Desarrolladas 
• Ethical hacking en IoT 
• Análisis de protocolos de red 
• Identificación de vulnerabilidades 
• Hardening de dispositivos IoT 
• Conciencia de seguridad 
  
Proyecto 10: Sistema de Detección de Intrusiones en Red IoT 
Sector Ciudades inteligentes (Smart Cities) 
Área Tecnológica IoT Hacking y Ciberseguridad 
Complejidad Avanzado 
 
Las redes IoT son vulnerables a ataques específicos (MITM, flood, escaneos) que los 
IDS tradicionales no detectan efectivamente, dejando infraestructuras críticas expuestas 
a compromisos de seguridad. 
Objetivo General 
Implementar un sistema de detección de intrusiones (IDS) especializado para redes IoT 
que identifique patrones de ataque mediante análisis de tráfico en tiempo real. 
Objetivos Específicos 
28. Configurar Suricata/Snort en Raspberry Pi con reglas personalizadas para ataques 
específicos de IoT. 
29. Implementar análisis de tráfico con Zeek para identificar comportamientos anómalos 
en protocolos IoT. 
30. Desarrollar dashboard de seguridad que visualice eventos, alertas y métricas de 
amenazas detectadas. 
 
Descripción 
IDS (Intrusion Detection System) basado en Raspberry Pi que monitorea tráfico de red 
IoT, detecta patrones anómalos, escaneos de puertos y ataques comunes como MITM o 
flood attacks. 
Hardware Necesario 
• Raspberry Pi 4 (4GB RAM) 
• Adaptador WiFi USB adicional (modo monitor) 
• Switch con port mirroring (o hub pasivo) 
• ESP32 (3 unidades - dispositivos IoT legítimos) 
• Arduino UNO (dispositivo atacante simulado) 
• LEDs indicadores de alertas 
Software y Tecnologías 
• Suricata o Snort (IDS open source) 
• Zeek (análisis de tráfico) 
• Python para scripts personalizados 
• Elasticsearch + Kibana para logs (opcional: Grafana) 
• MQTT broker 
• Reglas personalizadas Snort 
Habilidades Desarrolladas 
• Implementación de IDS 
• Análisis forense de red 
• Creación de reglas de detección 
• Gestión de logs de seguridad 
• Respuesta a incidentes

Control de acceso a edificio inteligente con autenticación de múltiples factores (RFID + 
PIN + biometría facial opcional), con cifrado end-to-end y logging de intentos de acceso.

Software y Tecnologías

• Cifrado AES para comunicaciones 
• MQTT con TLS/SSL 
• PostgreSQL para logs de acceso 
• Hashing bcrypt para PINs 
• Tokens JWT para sesiones 
Habilidades Desarrolladas 
• Implementación de MFA 
• Criptografía aplicada 
• Gestión segura de credenciales 
• Auditoría de accesos 
• Diseño de sistemas seguros

Sector Infraestructuras energéticas y redes 
eléctricas inteligentes

Habilidades Desarrolladas 
• Implementación de honeypots 
• Análisis de amenazas 
• Threat intelligence 
• Configuración de servicios señuelo 
• Análisis de comportamiento de atacantes

Proyecto 13: Plataforma de Análisis Predictivo para Consumo Energético

Nutrientes 
Sector Agricultura vertical y urbana 
Área Tecnológica SBC-IoT + AIoT 
Complejidad Avanzado 
 
Resumen Breve 
Sistema automatizado para cultivos hidropónicos que monitorea y controla pH,

Problemática 
La hidroponía requiere control preciso y constante de parámetros químicos de solución 
nutritiva, proceso manual tedioso y propenso a errores que afecta rendimiento de 
cultivos y puede causar pérdidas totales por desbalances nutricionales. 
Objetivo General 
Desarrollar un sistema de control automatizado para cultivos hidropónicos que 
mantenga parámetros óptimos de solución nutritiva mediante monitoreo continuo y 
dosificación automática de correctores. 
Objetivos Específicos 
145. Implementar sensores de pH, EC, temperatura y nivel de solución con bombas 
dosificadoras peristálticas para ajustes automáticos. 
146. Desarrollar algoritmos de control PID que mantengan pH y EC en rangos 
óptimos específicos por tipo de cultivo. 
147. Crear recetas de cultivo personalizables que ajusten parámetros según fase de 
crecimiento (vegetativa, floración, fructificación). 
 
Hardware Necesario 
• Raspberry Pi 4 
• Arduino Mega (control de actuadores) 
• Sensor de pH analógico 
• Sensor de EC/TDS 
• Sensor de temperatura DS18B20 waterproof 
• Sensor de nivel ultrasónico 
• Bombas peristálticas (4 unidades) 
• Bomba de aire para oxigenación 
• Relés de 8 canales 
• Electroválvulas 
• Display LCD 20x4 
Software y Tecnologías 
• Python con GPIO 
• Algoritmos de control PID 
• Node-RED para automatización 
• InfluxDB para series temporales 
• Grafana para monitoreo 
• MQTT para comunicación 
• Librería de recetas de cultivo 
• Alertas por Telegram 
• Calibración automática de sensores 
Parámetros Controlados 
• pH de solución (5.5-6.5 según cultivo) 
• Conductividad eléctrica (1.0-3.0 mS/cm) 
• Temperatura de solución (18-22°C) 
• Nivel de solución nutritiva 
• Oxígeno disuelto (indirecto) 
• Dosificación de pH+ y pH- 
• Dosificación de fertilizantes A y B 
• Recirculación de solución 
Habilidades Desarrolladas 
• Hidroponía automatizada 
• Control PID aplicado 
• Química de soluciones nutritivas 
• Calibración de sensores químicos 
• Sistemas de dosificación automática 
• Agricultura de precisión
